# Changelog

All notable changes to this project are documented in this file.

## [v1.0.0] - 2026-05-04

### Summary
Initial publication of the Bank Security Application as a clean Spring Boot banking and security project.

### Highlights

- Added customer and admin registration flows.
- Added JWT login and stateless security configuration.
- Added account opening, balance lookup, nominee updates, and KYC updates.
- Added card application, blocking, and limit management.
- Added investment creation from customer balances.
- Added documentation for the API surface and run steps.

### Notes

This version establishes the project as a compact learning showcase for building a secured banking API with Spring Boot, JPA, and JWT authentication.
